# [~Re] Leave-One-Out Stable Conformal Prediction

A partial replication, with an independent primary implementation and code-informed diagnostic variants, of

> K. Lee and Y. Zhang, *Leave-One-Out Stable Conformal Prediction*, ICLR 2025, **arXiv:2504.12189v1**
> (https://arxiv.org/abs/2504.12189v1). The original PDF and LaTeX source are not in this repository. `scripts/get_data.sh` can fetch the arXiv e-print when figure digitization needs the source plots.

It is written for submission to [ReScience C](https://rescience.github.io/). The article is in `article/`
(`article/article.pdf`). The author-supplied AI-use disclosure is included. ORCID is intentionally absent. The contact email and public code URL are in `article/metadata.yaml`. Links for the submission issue are in [Submission links](#submission-links) below.

The revision distinguishes empirical support from guarantees. C1/C3/C4 are reproduced within the tested scope, C2/C7/C8 are partially reproduced, and C5/C6 are reproduced with qualifications. The original authors were not contacted. ReScience's expectation of a contact attempt for failed replications remains an editorial consideration; the partial label does not establish an exemption.

## Clean-room protocol

1. A private note (`NOTES.md`) was written from the paper alone. It listed the claims, what the paper specifies and what it leaves open. That note is not in this public snapshot. The same record is in the article appendix, `TRACEABILITY.md`, and `DISCREPANCIES.md`.
2. `src/loostab/` was implemented from the paper text only, in numpy, numba and scikit-learn (no cvxpy, no PyTorch).
   Every function and non-trivial line carries a citation tag such as `# [Alg. 1, line 4]` or `# [App. G.1]`.
   Choices the paper leaves open are tagged `# [ASSUMPTION: ...]`.
3. The author states that all primary experiments were run and committed in a private archive **before** the authors' repository was opened.
   That private state was tagged `pre-diagnosis`. The tag is not in this public repository, and `git diff pre-diagnosis` does not work here.
4. Only then was <https://github.com/KiljaeL/LOO-StabCP> (commit `3b37682`) consulted to diagnose gaps. Source-derived choices are opt-in diagnostic *variants*, and each such line is tagged
   `# [FROM AUTHORS' CODE: file:line, commit]`. See `DISCREPANCIES.md`.
5. Later the authors' ICLR 2025 supplementary material was consulted (proceedings.iclr.cc, "Supplemental" zip, sha256
   `7f39cd75fda4e126ebdf5f545b34c3dbe2208f6216086e4137f23ef82a765e53`), an earlier, fuller version of their code with
   the neural-network, kernel and derandomisation scripts and raw result files. It is fetched by
   `scripts/get_data.sh` into `data/authors_supplement/` (git-ignored, not redistributed). Choices taken from it are
   tagged `# [FROM AUTHORS' SUPPLEMENT: file:line]`. The kernel code (`src/loostab/kernels.py`, claim C6) was written
   after reading it and is therefore **not** clean-room.

`TRACEABILITY.md` maps each paper element (section, equation, algorithm line, table, figure, hyperparameter) to
`file:line`, and lists every ASSUMPTION, FROM AUTHORS' CODE and FROM AUTHORS' SUPPLEMENT tag. It is generated by `tools/traceability.py`.

## Public history

Git history on this GitHub repository starts from a sanitized snapshot. It does not include the private pre-diagnosis commits or the private tags `pre-diagnosis` and `pre-diagnosis-screening`. The author states that the primary experiments were committed in that private archive before the authors' repository was opened, and that the screening text implementation was committed before the authors' screening code was read. Those sentences are the author's chronology. Commits and tags on GitHub are not a public verification of it. The original paper, the authors' supplement and result files, the Kaggle screening CSV, local run logs, and private notes are not in this repository. `scripts/get_data.sh` and `data/README.md` describe the fetches that are checksummed.

## Running

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
PY=.venv/bin/python bash run_all.sh          # ~36 min on 4 cores, CPU only
bash article/build.sh                        # needs tectonic + biber on PATH
```

Seeds are fixed (`experiments/run.py`: `SeedSequence([20250416, crc32(setting), rep])`), so the same machine gives
bit-identical results. BLAS is pinned to one thread.

### Variants (`--variant`)

| Variant | Meaning |
|---|---|
| `text` (default) | paper text, read literally (primary results) |
| `centered` | sim only: subtract the training mean of Y (sensitivity check, chosen before diagnosis) |
| `a_dgp` | sim: the supplement's DGP (text AR(1) design, ‖β‖² = 1/d; produced Table 2) |
| `a_dgp_github` | sim: the repository's later DGP (X ~ N(0, I/d), ‖β‖² = 1/d) |
| `a_scale` | real/NN: X additionally divided by √d after z-scoring |
| `a_coupled` | SGD: one set of R permutations of n+1 indices shared by all fits (as in the proof of Thm 3) |
| `a_cpdetails` | the authors' quantile without ∞, RO ỹ = 0, FullCP grid [min−sd, max+sd] with first/last accepted point, split ⌊0.7n⌋ |
| `a_oursnet` | NN: `a_scale` + `a_coupled` + `a_cpdetails`, the initial network |
| `a_sknet` | NN: `a_oursnet` with the supplement's scikit-learn network (ReLU, squared loss, mini-batch, momentum, seed 42), Eq. (8) bound |
| `a_kparams` | kernel: only the supplement's kernel parameters (RBF γ = 0.1, η = 1e-5), text design |
| `authors` | all of the authors' choices (sim: `a_dgp`; real: K = 50 for MM/EM; NN: `a_sknet` + constant bound Rη; kernel: `a_kparams` + `a_dgp`) |
| `authors_github` | as `authors`, but with the repository's DGP and K = 30 (what the repository alone implies) |
| `authors_centered` | kernel: `authors` with Y centred at its training mean (diagnosis of C6) |

Screening variants (`experiments/screen.py --variant ...`; DISCREPANCIES.md D12–D16):

| variant | meaning |
|---|---|
| `text` (default) | §6 as written: 20% test, fresh split each of 1000 reps, cfBH 70/30, App. G.1 bounds |
| `a_split` | the authors' split setup: 30% test, split redrawn only every 100th rep (10 distinct splits) |
| `a_xscale` | the authors' features: all columns z-scored, /√(p+1), plus intercept |
| `a_tau` | the authors' LOO-cfBH training bound without the factor R (a bug) |
| `a_cal50` | cfBH 50/50 train/calibration |
| `authors` | all of the authors' choices (also BH ≤, ỹ = 0, shared shuffles) |
| `authors_resplit` | `authors` but with a fresh split every rep |
| `authors_fixtau` | `authors` but with the App. G.1 bound restored |

## Scope

Evaluated, with mixed outcomes rather than uniform replication: §4 simulation (Table 2, Fig. 1), §5 real data (Table 3, Fig. 2), §5 and App. A.2 neural networks
(Figs. 3, 6), App. A.1 kernels (Fig. 5; needs the supplement's unreported parameters), App. B derandomisation
(Figs. 7, 8), and §6 screening (Table 4, Fig. 4).

The screening data (Kaggle, listed as CC0) is **not** included (`scripts/get_data.sh` copies the identical
`recruit.csv` from the authors' supplement if it has been fetched). Download `Placement_Data_Full_Class.csv` from
https://www.kaggle.com/datasets/benroshan/factors-affecting-campus-placement (free login) into `data/screening/`
before running the screening part; see `data/README.md`.

## Data and ethics

`data/diabetes.csv` is included. It is the Efron et al. (2004) table exported from scikit-learn (`load_diabetes(scaled=False)`); scikit-learn is BSD-3-Clause. Boston Housing is not included: the pinned mirror (`selva86/datasets`) has no license file. `scripts/get_data.sh` downloads `data/BostonHousing.csv` and checks sha256 `ab16ba38fbbbbcc69fe930aab1293104f1442c8279c130d9eba03dd864bef675`, and the loader writes `data/boston.csv`. The Boston
feature `B` is computed from the proportion of Black residents per town, and the dataset has been withdrawn from
scikit-learn for this reason. It is used only to replicate the paper's numbers, as discussed in the article.
